# Before publishing

This is a prepared source preview, not an uploaded GitHub repository.

1. Confirm contributor attribution and authority to use the existing ISC license.
2. Resolve redistribution permission/provenance for the trained regressors and
   reference texts before adding assets. Keep private data out even if a model
   license permits weights. Record approved asset hashes and immutable sources.
3. Resolve or prominently retain numerical parity failures; do not market an
   unvalidated preview as a validated research instrument.
4. Refresh dependency/security checks and complete intended-browser/manual tests.
5. Review every file in this preview. The automated scan is a heuristic, not a
   guarantee that all secrets or ownership issues have been identified.
6. Publish from a NEW repository initialized in this sanitized directory. Do not
   push the existing project history: research documents are already tracked there.
   Adding a gitignore does not remove files from history.
7. Add only reviewed preview files; inspect git diff --cached and run a dedicated
   secret scanner before the first push. Confirm visibility and owner separately.
8. If distributing a complete extension later, include all upstream licenses,
   installation/privacy/limitations docs, approved assets and checksums. Do not
   upload old extension ZIPs or dist backups as a shortcut.

Excluded: original .git, research/, reports/, handoff/, tmp/, browser profiles,
node_modules/, dist/, existing ZIPs, duplicate '- Copy' files, model export,
parity reference texts and all runtime binaries. No original project files were
modified to create this preview.
